USER SCRIPT · GUIDE

外宣邀约填表助手

日常共用版

这是一个只对外宣系统（wx.qgxkt.doupeixun.cn）生效的浏览器脚本，用来省掉每天登记邀约时的重复操作。所有关键动作都由你自己把关，最后的提交按钮永远留给你本人来点。

FEATURES

六个常用功能

01

多开同页面，支持拖动排序与改名

原网站不允许同时开两个一样的页签，装上脚本后，页签栏右侧会出现一个 ＋ 号（或者直接在页签上点右键），点一下就能把当前列表页再复制一份，分别设不同的筛选条件，比如一边看培训与流失，一边盯今天待面试的名单。按住页签拖动可以调整顺序，双击标题可以直接改名。

02

首页数据看板 左上角小房子图标 / 列表页主·仪表盘

进入系统后，点左上角的小房子图标（或独立列表页右上角的主 · 仪表盘）就能打开数据概览，里面按总计、月报和日报三块整理好了常用人数，最下方是本月每天的有效趋势折线图。打开页面不会自动联网拉数据，需要看最新情况时点右上角刷新全部即可，也可以单独点刷新入职、刷新月报或刷新日报。月报右上角支持设置默认岗位、目标人数和月份；日报支持直接切看今天、昨天、前天或任意指定日期。左上角 << 按钮还可以一键收起或展开左侧边栏。

03

多选批量到场 / 撤销到场 顶栏 多 / 列表页 多选 · 到场

点页签栏右上角的 多（或独立列表页右上角的多选 · 到场）进入多选状态，勾选要处理的记录后，点顶部紫色操作条里的批量到场或批量撤销到场（也可以直接点其中某一行的到场按钮），脚本会自动逐条处理完再统一刷新列表，不用一条一条等页面重载。

04

打开新增时自动填入常用项（支持自选默认岗位）

打开新增弹窗会自动填好下面几栏；其中面试岗位可以在仪表盘月报目标左边的下拉框里提前选好（包含系统全部 9 个岗位，选不选择则会保持留空不预填）。平时如果大多招某一个岗位、偶尔需要临时改选别的（比如默认运营助理、临时改助播），直接在表单里手改即可，不会和你抢输入框。

登记日期当天 招聘渠道外宣BOSS直聘 面试岗位看板可选（含留空） 性别男
05

自动挑选最近还有名额的时段

选好基地和社区后，脚本会自动查看各时段还剩多少空位，帮你在近期有空的那一天选好最早可约的日期、小时和分钟（今天有空约今天，约满了自动顺延到后面几天，最多往后看 10 天）。最近一次用过的基地和社区也会自动记住，下次打开直接带出来。

06

快捷粘贴填入 Alt + Shift + V / 贴

在网站任意页面按 Alt + Shift + V，或者点页签栏的 贴（独立列表页为贴 · 填表），可以呼出粘贴框导入整理好的 JSON 数据一次填完；平时不用时完全不会干扰手动填表。

WINDOWS 10 · EDGE

Win10 Edge 权限提醒

新版 Edge 里的篡改猴默认限制脚本权限。如果装完后刷新网站看不到 ＋ 号、也没有小房子仪表盘，把下面两项开关打开即可：

01

在地址栏打开 edge://extensions/ ，打开页面里的开发人员模式开关。

02

点开 篡改猴 的详细信息，往下拉找到允许用户脚本并开启，确认站点访问权限包含当前外宣网站。

03

回到外宣网站按 Ctrl + F5 强刷一次页面即可生效（按 F12 看控制台有 [邀约助手] 就绪 字样即正常）。

FAQ & PRIVACY

常见问题

页签上没看到 ＋ 号或 贴 按钮？

先按右边 Win10 Edge 的步骤确认权限已开，再强刷一次页面。注意 ＋、贴、多 这三个按钮只在带左侧菜单和顶部页签栏的主框架里显示；单独打开列表页时，入口会放在列表右上角新增按钮下方。

火狐浏览器（Firefox）能用吗？

可以。不管是装篡改猴还是 Greasemonkey（油猴子），仪表盘、多选批量到场和自动填表都能正常用。

点开新增后没有自动填进去？

偶尔页面刚加载完初始化慢，等一两秒或关掉弹窗重开一次即可。如果一直没反应，按 F12 切到控制台，输入 __dshWxDiag() 回车可以把当前状态打印出来方便排查。

以后不想用了怎么关掉？

点右上角篡改猴图标，直接把开关关掉或删掉脚本就行，不会影响原网站任何数据。

这个脚本只在 wx.qgxkt.doupeixun.cn 下生效，不会读取其他网站；所有查询和填表都只用你当前的登录态直接请求原网站接口，不经过任何第三方服务器。
