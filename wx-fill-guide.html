  • 总计展示全时段已培训 / 流失 / 总入职；

05

页签能多开，还能拖拽换序与重命名

网站原生不允许同一个页面开两个页签，装上脚本后：

  • 顶栏与页签栏已合并精简，页签栏右边有 「＋」（已自动隐藏多余的 << / > 按钮），点一下即可把当前页签再开一个，各自独立设置筛选条件；

  • 每次打开或刷新主界面时，会自动折叠左侧边栏并默认额外打开一个「邀约列表」页签（焦点仍停留在主页）。

Win10 Edge 必看

完全没反应 / 看不到「＋」和日志时：Win10 Edge 商店版的篡改猴已升级到 Manifest V3（5.x），如果安装后页面完全没有「＋」、按 F12 也没有 [邀约助手] 日志，按下面两步开启权限即可：

01

地址栏打开 edge://extensions/ ，开启「开发人员模式」（页面左下角或右上角开关）。

02

找到「篡改猴（Tampermonkey）」→ 点「详细信息」 → 往下拉确认开启「允许用户脚本」（Allow user scripts），且站点访问权限包含外宣网站。

03

回到外宣网站按 Ctrl + F5 强刷一次页面，按 F12 控制台出现 [邀约助手] 就绪（...，二合一版） 即生效。

FAQ & PRIVACY

常见问题

页签上没出现「＋」或顶栏小房子？

先按上面的 Win10 Edge 权限检查；确认刷新过页面；再看你盯的是不是网站最外层（页签栏只在最外层；列表页本身是嵌在里面的）。

火狐（Firefox）或沙箱模式

同样能用。脚本内置跨沙箱与跨 iframe 桥接（runInDoc）、默认页签重试与自定义月份选单，即便读不到页面全局也能正常开页签、选月份、刷新下拉框和剩余人数红字。

打开「新增」没自动填？

刷新一次页面再试。还不行就按 F12 打开控制台，输入 __dshWxDiag() 回车，即可看到诊断信息。

不想要了

篡改猴面板里把这条脚本删掉即可，网站本身不受影响。

这个脚本只对 wx.qgxkt.doupeixun.cn 生效（脚本头里写着 @match），不会读你别的网页；它只调网站自己的接口，不往任何第三方发数据。
