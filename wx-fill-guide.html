FEATURES

它帮你做六件事

01

页签能多开，还能拖拽换序与重命名

网站的页签不允许同一个页面开两个（它按网址去重），装了这个之后，页签栏右边会多一个 「＋」（已自动隐藏原本重合的右箭头 >），点一下就把当前页签再开一个，每个可以各设一套筛选条件（比如一个看“培训/流失”，一个看“当天等待面试”）。在某个页签上点右键也能复制那一个；按住页签拖拽可调整顺序，双击页签标题可直接重命名。

02

主页数据仪表盘 左上角小房子图标 / 独立列表页「主 · 仪表盘」

进入工作台时，左上角原本无用的 小房子页签 已直接替换为数据主页（默认只读取本地 localStorage 缓存、不自动联网请求，且切看历史日期不会覆盖今日缓存，需要最新数据时点一下右上角「刷新全部」即可）；按总计 → 日报 → 月报顺序依次刷新，展示总计（已培训 / 流失 / 总入职）、月报（2:3:2 排布：入职 / 有效 / 到面数，右上角可填目标人数联动底部同色系自适应高度进度折线图）、以及日报（等待面试 / 已面试 / 有效 / 无效，支持切换任意一天单独即时刷新）；左上角 << 按钮已改为收起/展开左侧边栏。

03

多选条目统一到场 / 撤销到场 「多」按钮 / 「多选 · 到场」

点页签栏右上角 「多」（或独立列表页右上角 「多选 · 到场」）开启多选模式后，可自由勾选多条记录，然后直接点顶部紫色操作栏上的 「批量到场」/「批量撤销到场」（或任意一行的 「到场」/「撤销到场」），脚本会批量依次提交选中条目并在全部完成后统一刷新一次列表，避免单条点击频繁刷新页面。

04

打开「新增」时自动填好固定项

登记日期今天 招聘渠道外宣BOSS直聘 面试岗位运营 性别男
05

自动挑最近一个还能填的时段

选完基地 + 社区之后，它会问网站自己（可约时段 + 单小时上限 + 当前已约人数），把「预约面试时间」的日期、时、分都选好 —— 今天还有空就今天，今天满了就往后顺延（最多看近 10 天），全满会提示你自己定。上次用过的基地/社区会记住，下次自动带出来。

06

粘贴核心信息一键填表 工作台联动 / 手动呼出

  • 从工作台点「填到网站」跳过来（地址带 #dsh-fill=）时，会自动读剪贴板或弹出粘贴框填入；
  • 平时在网页任意位置按 Alt + Shift + V，或点页签栏右上角的 「贴」（独立列表页右上角为 「贴 · 填表」），也能随时呼出粘贴框手动填入；不用它时完全不打扰日常手填。

WINDOWS 10 · EDGE

Win10 Edge 必看

完全没反应 / 看不到「＋」和日志时：Win10 Edge 商店版的篡改猴已升级到 Manifest V3（5.x），如果安装后页面完全没有「＋」、按 F12 也没有 [邀约助手] 日志，按下面步骤开启权限即可：

01

地址栏打开 edge://extensions/ ，开启「开发人员模式」（页面左下角或右上角开关）。

02

找到「篡改猴（Tampermonkey）」→ 点「详细信息」 → 往下拉确认开启「允许用户脚本」（Allow user scripts），且站点访问权限包含外宣网站。

03

回到外宣网站按 Ctrl + F5 强刷一次页面，按 F12 控制台出现 [邀约助手] 就绪（...，二合一版） 即生效。

FAQ & PRIVACY

常见问题

页签上没出现「＋」或「贴」？

先按上面的 Win10 Edge 权限检查；确认刷新过页面；再看你盯的是不是网站最外层那一层（页签栏只在最外层；列表页本身是嵌在里面的）。

火狐（Firefox）或沙箱模式可以用吗？

同样能用。脚本内置跨沙箱与跨 iframe 桥接（runInDoc），即便读不到页面全局也能正常开页签、刷新下拉框和剩余人数红字。

打开「新增」没自动填？

刷新一次页面再试。还不行就按 F12 打开控制台，输入 __dshWxDiag() 回车，即可看到诊断信息。

不想要了怎么办？

篡改猴面板里把这条脚本删掉即可，网站本身不受影响。

这个脚本只对 wx.qgxkt.doupeixun.cn 生效（脚本头里写着 @match），不会读你别的网页；它只调网站自己的接口，不往任何第三方发数据。
